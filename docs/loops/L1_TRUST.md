## Current state (read 2026-10-25; T0 re-verifies)

- Identity lives in process-wide variables that any request overwrites: `server.ts#let currentUserId = 'usr_admin';`, `server.ts#if (reqUser) currentUserId = reqUser;`. The client sends whatever identity it likes: `src/lib/api.ts#'x-user-id': this.userId,`.
- Routes that read or change other tenants' data, because they never compare the org: `server.ts#res.json({ integrations: state.integrations });`, `server.ts#res.json({ evaluations: state.evaluations });`, `server.ts#res.json({ deployments: state.deployments });`, `server.ts#res.json({ auditLogs: visible.slice(0, 50) });`, `server.ts#res.json({ approvals: state.approvals });`, `server.ts#for (const doc of state.knowledge) {`, `server.ts#const idx = state.knowledge.findIndex((k) => k.id === req.params.id);`, `server.ts#const exec = state.executions.find((e) => e.id === req.params.id);`, `server.ts#const existing = state.agents.find((a) => a.id === req.params.id);`. Integrations have no tenant field at all: `server/storage.ts#export interface ToolIntegration {`.
- Deployment keys are returned by the unfiltered list above, generated with `server.ts#const randomHex = Math.random().toString(36).substring(2, 10);` or `server.ts#nx_live_ft_`, and compared with `server.ts#token !== deployment.apiKey`. `server.ts#/api/v1/deployments/:id/test-invoke` runs a deployment with no key at all.
- Roles are defined (`server/storage.ts#role: 'org_admin'`) and nothing checks them. An approval records whoever the global variable names: `server.ts#approval.decidedBy = currentUserId;`.
- Persistence rewrites the whole file, not atomically: `server/storage.ts#fs.writeFileSync(DATA_FILE, JSON.stringify(state, null, 2), 'utf-8');`. Write failures are only logged: `server/storage.ts#console.error('Failed to write store file:', e);`. An unreadable file at boot is replaced by seed data: `server/storage.ts#this.saveState(seed);`.
- Stored and never enforced: `server.ts#rateLimitPerMinute: Number(rateLimitPerMinute) || 120,`. Body size limit: `server.ts#app.use(express.json({ limit: '10mb' }));`.
- No outbound HTTP call exists in `server.ts` or the server directory (searched for fetch, new URL and http.request on 2026-10-25). Connector URLs are user-supplied: `server.ts#baseUrl: baseUrl || 'https://api.internal.enterprise/v1',`.
- Audit export covers every tenant and quotes cells without neutralizing formulas: `server.ts#nexus_audit_events.csv`.
